# Ruby 4.0.2 アップグレード Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ruby を 3.3.11 → 4.0.2 へ直行アップグレードする（Rails 8.1.3 据え置き）。

**Architecture:** バージョン番号 2 ファイル（`.ruby-version`・`Dockerfile`）の bump を起点に、bundler 4.x bump → `gem "cgi"` 予防追加 → frozen_string_literal 一括付与 → docs の 4 コミットを 1 PR に積む。各コミットの受け入れは「既存 green suite（rspec 523/rubocop/brakeman）の再 green」。frozen 付与は文字列リテラルを hard-freeze 化するため mutation 監査を伴う。

**Tech Stack:** Ruby 4.0.2 / rbenv / Bundler 4.0.6 / Rails 8.1.3 / RSpec / RuboCop(omakase) / Brakeman

設計の正本: `docs/superpowers/specs/2026-06-14-ruby-4-0-2-upgrade-design.md`

## 既知の罠（RAILS_GOTCHAS + 本検証由来・計画に注入）

- **`bundle install` では BUNDLED WITH は上がらない** — bundler は lock の `BUNDLED WITH 2.5.22` を尊重し 2.5.22 を使う。4.x へ上げるには **`bundle update --bundler` の明示実行**が必要（本検証で実踏）。
- **rubocop の TargetRubyVersion 4.0 拒否の可能性** — `.ruby-version`=4.0.2 から rubocop が target 4.0 を推論し、rubocop 1.87 が未知版としてエラーにし得る。Task 1 に contingency あり。
- **frozen_string_literal は chilled より強い** — 磁気コメント付与で文字列は真に freeze、mutation は即 FrozenError。green suite を安全網に監査（Task 3）。
- **ruby-vips は環境要因** — ローカルのみ libvips 未導入で `require "vips"` 失敗。3.3.11 でも同一・Ruby 4.0 回帰ではない。`require: false` + 遅延ロードゆえ suite 無影響。本番 Docker は libvips 同梱。
- **rbenv ビルドは OpenSSL 回避策必須** — `RUBY_CONFIGURE_OPTS=--with-openssl-dir=$(brew --prefix openssl@3)` + LDFLAGS/CPPFLAGS/PKG_CONFIG_PATH クリア（CLAUDE.md）。

- [ ] **Step 4: mutation 監査 — 全 suite で FrozenError を炙り出す**

Run: `bundle exec rspec`
Expected: 理想は `0 failures`。**FrozenError が出たら**、backtrace の該当行が「凍結文字列リテラルを mutate している箇所」。次の Step で修正。

- [ ] **Step 5: FrozenError の修正（出た場合のみ・出なければスキップ）**

該当行を非破壊化する。典型パターン:
```ruby
# NG: 凍結リテラルを破壊的変更
buf = ""
buf << "x"            # FrozenError

# OK-1: mutable な文字列で開始（unary +）
buf = +""
buf << "x"

# OK-2: dup してから変更
s = some_literal.dup
s.gsub!(/.../, "...")

# OK-3: 非破壊メソッドへ置換
s = some_literal.gsub(/.../, "...")   # gsub!→gsub
```
修正後 `bundle exec rspec` を再実行し `0 failures` まで反復。

- [ ] **Step 6: full rubocop で no offenses を確認**

Run: `bundle exec rubocop --force-exclusion`
Expected: `no offenses detected`（frozen string cop 込み）。
